# Oficina Virtual 3D

Espacio creativo personal desarrollado desde Android con UserLAnd,
Node.js, Three.js y TSL.

## Objetivos

- Crear una oficina 3D inmersiva e interactiva.
- Organizar imágenes, prompts y recursos creativos.
- Integrar un espacio dedicado a la música.
- Mantener el código versionado con Git y respaldado en GitHub.

## Estado

Fase inicial: preparación del entorno de desarrollo.
